# Hotel demo media sources

The hotel hero images in this directory were collected from public Iran Hotel
Online listing pages on 2026-09-29 for a private client-facing prototype.
Hotel names, star classes, locations and review snapshots are source-backed;
prices, availability, cancellation policies and room inventory are fictional.

These images are reference assets, not an assertion of ownership or a reusable
commercial license. Replace or license them before a public production launch.
