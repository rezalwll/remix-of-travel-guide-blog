# نگاشت intent و نوع صفحه در بازار

تاریخ بررسی: 2026-09-27

هدف این سند تعیین **یک صفحهٔ canonical برای هر intent** است، نه تولید صفحه برای هر مترادف.

| خانوادهٔ عبارت | intent | نوع صفحهٔ غالب مشاهده‌شده | تصمیم کیاشی | صفحهٔ canonical نمونه |
|---|---|---|---|---|
| بلیط تهران مشهد / پرواز تهران مشهد / بلیط هواپیما تهران مشهد | خرید/مقایسه مسیر | route landing با ویجت و راهنمای مسیر | یک `FLIGHT_ROUTE`، بدون صفحهٔ مترادف | `/flights/tehran-to-mashhad` |
| بلیط تهران استانبول / پرواز تهران استانبول | خرید مسیر بین‌المللی | route landing + فرودگاه/مدارک/هتل | یک `FLIGHT_ROUTE` با منبع و پیوند فرودگاه | `/flights/tehran-to-istanbul` |
| بلیط مشهد / پروازهای مشهد | کشف پروازهای شهر | flight-city در برخی رقبا | فعلاً ادغام در destination + route allowlist؛ صفحهٔ مستقل فقط با محتوای کافی | `/destinations/iran/mashhad` |
| هتل کیش / رزرو هتل کیش | اقامت در شهر | hotel-city listing/hub | یک `HOTEL_CITY`؛ search params noindex | `/hotels/kish` |

| هتل استانبول / رزرو هتل استانبول | اقامت خارجی | hotel-city + محله + property | یک `HOTEL_CITY`، بدون ادعای inventory | `/hotels/istanbul` |
| تور استانبول / تور لحظه آخری استانبول | پکیج و راهنمای تور | tour-destination با inventory جاری | `TOUR_DESTINATION` evergreen؛ inventory آینده جدا و provider-backed | `/tours/istanbul` (فعلاً فقط پس از gate) |
| تور کیش | پکیج داخلی | tour-destination | یک صفحه evergreen، نه صفحهٔ فصلی جدا | `/tours/kish` (پس از gate) |

| فرودگاه امام خمینی / راهنمای فرودگاه امام | راهنمای فرودگاه | airport guide | `AIRPORT_GUIDE` با منبع رسمی و تاریخ بازبینی | `/airports/imam-khomeini` (پس از gate) |
| فرودگاه استانبول / رفت‌وآمد فرودگاه استانبول | راهنما/ترنسفر | airport guide + مقاله | یک airport guide؛ هزینه/زمان متغیر با منبع و تاریخ | `/airports/istanbul` (پس از gate) |

## الگوی SERP و تصمیم معماری

- عبارت تجاری مسیر باید به route landing برسد، نه search URL دارای تاریخ.
- عبارت هتل شهر باید به hotel-city hub برسد؛ sort، تاریخ، نفرات، قیمت، ستاره و امکانات canonical مستقل نمی‌سازند.
- عبارت «راهنمای سفر» به destination hub یا مقالهٔ واقعاً تخصصی می‌رود، نه صفحهٔ فروش.
- تور مقصد یک صفحهٔ evergreen دارد؛ پکیج‌های تاریخ‌دار دادهٔ زنده/کوتاه‌عمرند و نباید body ثابت سئو را تعیین کنند.
- ویزا و فرودگاه فقط با منبع رسمی، تاریخ بازبینی و سیاست freshness قابل index هستند.

## نتیجهٔ رقابتی

بازار نشان می‌دهد کاربران از صفحهٔ تجاری انتظار ابزار بالای صفحه و راهنمای تصمیم پایین صفحه دارند. کیاشی این ساختار را بدون کپی متن/طرح حفظ می‌کند، اما بین «راهنمای indexable» و «inventory زندهٔ provider» مرز صریح می‌گذارد و صفحات مترادف یا پارامتری را تولید نمی‌کند.
