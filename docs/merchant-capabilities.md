# قابلیت‌های پذیرندگان

سیاست مرجع در `server/platform/merchant-capabilities.ts` قرار دارد و علاوه بر منو، در routeهای سرور enforce می‌شود. داشتن permission به‌تنهایی برای ورود به ماژول محصول کافی نیست.

| نوع کسب‌وکار | قابلیت‌های محصول |
| --- | --- |
| `HOTEL` | مدیریت هتل، اتاق، نرخ، موجودی، رزرو و مهمان |
| `TOUR_OPERATOR` | مدیریت تور/زیارت، حرکت، ثبت‌نام و شرکت‌کننده |
| `TRAVEL_AGENCY` | سفارش‌های واگذارشده، تیم و مالی؛ بدون انتشار مستقیم محصول |
| `TRANSPORT_PROVIDER` | سفارش‌های واگذارشده و عملیات انتقال موجود |
| `SERVICE_PROVIDER` | سفارش‌های واگذارشده و عملیات سرویس موجود |
| `GENERAL_PARTNER` | سفارش‌های واگذارشده، تیم و مالی |

قابلیت‌های مشترک فقط دسترسی‌های واقعی فعلی را پوشش می‌دهند. افزودن business type یا permission تازه باید همراه با به‌روزرسانی policy و تست denial باشد.
