# سیاست منابع محتوای SEO

## اصل منبع

محتوای الهام‌بخش کم‌نوسان می‌تواند حاصل نگارش تحریریه باشد، اما ادعای عملیاتی یا حقوقی باید به مرجع رسمی و تاریخ بازبینی متصل شود. صفحه هرگز قیمت، ظرفیت، امتیاز، تعداد نظر، وضعیت ویزا یا زمان قطعی خدمت را از داده نمایشی استخراج نمی‌کند.

## سلسله‌مراتب منبع

1. وب‌سایت دولت، فرودگاه، راه‌آهن، ایرلاین یا مرجع رسمی مقصد.
2. سند رسمی یا اطلاعیه تاریخ‌دار همان نهاد.
3. منبع تخصصی معتبر برای زمینه عمومی؛ فقط اگر منبع رسمی پاسخ‌گو نیست.
4. محتوای رقبا فقط برای تحلیل ساختار و intent است، نه منبع حقیقت.

## ثبت منبع در کد

رکوردهای پرنوسان از نوع `SeoSource` شامل عنوان، URL، ناشر، تاریخ بررسی و پرچم رسمی هستند. گیت کیفیت برای `AIRPORT_GUIDE` و `VISA_COUNTRY` وجود حداقل یک منبع رسمی را الزامی می‌کند. لینک منبع روی صفحه فرودگاه نیز برای کاربر قابل مشاهده است.

## ممنوعیت‌ها

- بازنویسی ادعای رقیب به‌عنوان واقعیت.
- درج «ارزان‌ترین»، «تضمینی»، «صدور قطعی» یا ظرفیت/قیمت بدون داده معتبر.
- نمایش AggregateRating یا review ساختگی.
- به‌روزرسانی صوری تاریخ بدون بازبینی محتوا.
