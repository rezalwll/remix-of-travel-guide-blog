## Experimental Karbala references

The four files in `public/media/ziyarat/` were downloaded from the user-specified
[Nahalgasht Karbala tour page](https://nahalgasht.com/tours/iraq/karbala/) for a local visual
prototype. No reusable public license was found on the source page. They must be replaced with
licensed originals or used with the owner's permission before any public or commercial release.
