# برنامهٔ تمایز سئوی کیاشی

## موضع محصول

کیاشی با «صفحهٔ کمتر اما قوی‌تر» رقابت می‌کند. هدف این فاز ساخت انبار URL نیست؛ هدف ساخت گراف کوچکی از صفحه‌های سروررندر، فارسی، صادق و قابل نگهداری است.

## تصمیم‌ها

1. **کیفیت قبل از مقیاس:** فقط allowlist مقصد، مسیر، هتل شهر، تور و فرودگاه منتشر می‌شود. هر صفحه باید quality gate را پاس کند.
2. **مرز راهنما و موجودی:** متن راهنما evergreen و indexable است؛ قیمت، ظرفیت، تخفیف، برنامه و امتیاز فقط از provider/کاربر واقعی و در سطح مناسب نمایش داده می‌شود.
3. **فارسی تحریری بهتر:** مقدمه‌های تکراری و «تجربه‌ای فراموش‌نشدنی» حذف می‌شوند. متن باید به تصمیم مشخص کاربر کمک کند.
4. **معماری خوشه‌ای تمیز:** مقصد ← مسیر ← هتل شهر ← تور ← مقاله؛ پیوندها context-based و محدودند.
5. **بدون crawl trap:** query، sort، date، travelers، price، airline، amenity و pagination صفحهٔ canonical مستقل نمی‌شوند و از sitemap خارج‌اند.
6. **SSR واقعی:** صفحهٔ عمومی تا حد ممکن Server Component می‌ماند؛ client فقط برای جست‌وجو، تقویم و تعامل ضروری است.
7. **منبع و freshness:** واقعیت‌های پرنوسان منبع رسمی و `lastReviewedAt` می‌خواهند؛ در نبود آن generic، noindex یا deferred می‌شوند.
8. **schema محافظه‌کار:** WebSite، Organization، BreadcrumbList، Article/BlogPosting و FAQPage فقط وقتی دقیق‌اند. Offer، Review، AggregateRating، price و availability ممنوع‌اند تا دادهٔ واقعی وجود داشته باشد.
9. **تصویر بدون قربانی کردن crawlability:** alt توصیفی، ابعاد پایدار، sizes مناسب، lazy زیر fold و priority فقط برای LCP.
10. **بدون تقلید trade dress:** فقط الگوهای اطلاعاتی بازار اقتباس می‌شوند؛ copy، HTML، CSS، تصویر و payload ساختاریافتهٔ رقبا کپی نمی‌شود.

## معیار انتشار

صفحه فقط وقتی indexable است که عنوان، H1 و description یکتا؛ intro مفید؛ حداقل سه بخش خاص؛ حداقل دو پیوند زمینه‌ای؛ منبع/تاریخ مناسب؛ و عدم placeholder/ادعای زندهٔ جعلی داشته باشد. در غیر این صورت صفحه تولید نمی‌شود یا `noindex` می‌ماند.

## چیزهایی که عمداً انجام نمی‌دهیم

- تولید همهٔ مبدا×مقصد.
- صفحه برای مترادف‌ها.
- فوتر پر از exact-match anchor.
- ساخت Review/UGC یا نویسندهٔ متخصص خیالی.
- ادعای «ارزان‌ترین»، «بهترین»، تضمین ویزا یا موجودی زنده.
- بازگرداندن city-tours، eSIM یا fast-track.
- redesign رابط کاربری منجمد.
