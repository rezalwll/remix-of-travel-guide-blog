# بنچمارک بصری رقبای سفر (فاز UI Lockdown)

هدف این سند استخراج **الگوهای محصول** است، نه کپی هویت بصری، متن، تصویر یا چیدمان رقبا. هیچ دارایی بصری از این سایت‌ها دانلود یا استفاده نشده است.

## یافته‌های الگویی

### Jajiga
- **hero**: عنوان کوتاه + جست‌وجوی سریع، بلافاصله زیر آن «جست‌وجوی سریع» به شکل ردیف دسته‌های تصویری (کلبه، استخردار، لب آب، بوم‌گردی، …).
- **کشف با دسته‌بندی**: ده‌ها دستهٔ کوتاه به‌جای منوی عمیق؛ کاربر بدون فرم هم می‌تواند وارد قیف شود.
- **ردیف مقاصد پرطرفدار**: فهرست متنی متراکم «اجاره ویلا در رامسر/ماسال/…» که هم SEO و هم ناوبری را تغذیه می‌کند.
- **ریل‌های افقی محصول**: چند ریل پشت‌سرهم با عنوان و زیرعنوان («اقامتگاه‌های ممتاز»، «اقامتگاه‌های خاص»، «اقتصادی»، «لوکس») و در هر ریل کارت‌های عکس‌محور با CTA «مشاهده همه».
- **بلوک اعتماد**: سه ستون کوتاه (رزرواسیون ۲۴ ساعته، ضمانت تحویل، کم‌هزینه و باکیفیت).
- **نظرات کاربران**: بخش testimonial با نام و تاریخ عضویت.
- **متن SEO انتهایی**: پاراگراف بلند + ابرلینک‌های کلیدواژه‌ای در فوتر.

### Flytoday
- **نوار سرویس‌ها بالای فرم**: پرواز داخلی/خارجی/هتل/قطار/اتوبوس/ویلا/گشت/بیمه/CIP به‌صورت تب.
- **بنرهای کمپین**: کارت‌های بزرگ تصویری (ویزا، شوفر، سفرکارت) بلافاصله زیر فرم جست‌وجو.
- **ریل هتل‌های پرطرفدار**: کارت عکس‌محور با نام هتل + ستاره + «شروع قیمت از».
- **تفکیک داخلی/خارجی** با تب داخل همان بخش.
- **کارت‌های سرویس متقاطع**: خرید قسطی، راهکار سازمانی، اتوبوس، تور، قطار، هتل — هرکدام با تصویر و یک جملهٔ ارزش.
- **بلوک FAQ** در انتهای صفحه + فوتر بسیار لینک‌محور.

### الگوهای مشترک بازار ایران
- صفحهٔ اصلی طولانی و «کشف‌محور» است، نه صرفاً یک فرم جست‌وجو.
- کارت‌های محصول تقریباً همیشه عکس‌محورند؛ کارت متنی خالی تقریباً دیده نمی‌شود.
- تب‌بندی سرویس‌ها استاندارد بازار است و کاربر ایرانی انتظارش را دارد.
- بلوک اعتماد و پشتیبانی نزدیک انتهای صفحه تکرار می‌شود.

## آنچه کیاشی پذیرفت (مفهومی، نه کپی)

1. صفحهٔ اصلی طولانی با **ریتم بصری متنوع** به‌جای تکرار کارت متنی.
2. **ریل افقی** برای کشف مقصد/اقامت/تجربه (با پیاده‌سازی CSS scroll-snap، بدون JS اضافه).
3. **نوار دسته‌بندی تصویری** برای ورود سریع به قیف.
4. **بنر کمپین تمام‌عرض** برای مقصدهای فصلی.
5. **کارت سرویس متقاطع** برای سرویس‌های ثانویه (بیمه، CIP، ترانسفر، eSIM).
6. **بلوک اعتماد فشرده** نزدیک انتهای صفحه.
7. تفکیک روشن **محتوای راهنما** از **نتیجهٔ جست‌وجوی واقعی**.

## آنچه عمداً رد شد

| الگو | دلیل رد |
| --- | --- |
| نمایش «شروع قیمت از …» روی کارت‌های صفحهٔ اصلی | کیاشی هنوز تأمین‌کنندهٔ واقعی ندارد؛ قیمت نمایشی نباید مثل نرخ زنده جلوه کند. |
| ستاره و امتیاز و تعداد نظر روی کارت مقصد | داده‌های امتیاز فعلی دمو هستند؛ انتشارشان به‌عنوان واقعیت گمراه‌کننده است. |
| testimonial با نام و تاریخ کاربر | نظر واقعی کاربر وجود ندارد؛ ساختنش جعل است. |
| فوتر با ده‌ها ابرلینک کلیدواژه‌ای | ریسک اسپم و تضاد با دروازهٔ کیفیت SEO فاز ۲۲. |
| اسلایدر خودکار hero | آسیب به دسترس‌پذیری و CLS؛ hero ثابت با تصویر LCP بهینه انتخاب شد. |
| تراکم بالای بنر تبلیغاتی پشت‌سرهم | هدف بصری کیاشی «پریمیوم و خلوت‌تر» است، نه شلوغی بازارگونه. |

## تمایز هدف کیاشی

- خلوت‌تر و منظم‌تر از مارکت‌پلیس‌های متراکم.
- احساسی‌تر از OTAهای صرفاً ابزاری، با تکیه بر تصویر به‌عنوان سطح محصول.
- صادق‌تر از سایت‌های پرومو-محور: هیچ ادعای تجاری بدون تأمین‌کنندهٔ واقعی.
- یکدست‌تر از پورتال‌های دسته‌محور: یک سیستم کارت، یک سیستم رسانه، یک زبان رنگی.
