# راهنمای نگارش فارسی کیاشی

## لحن

فارسی روشن، مستقیم و کاربردی بنویسید. مخاطب باید بداند چه چیزی را بررسی کند، نه اینکه با شعار قانع شود. از نیم‌فاصله استاندارد، اعداد فارسی در متن نمایشی و نام لاتین/کد IATA فقط هنگام نیاز استفاده کنید.

## عنوان و metadata

- H1 یکتا، طبیعی و هم‌راستا با intent باشد.
- title بین نام موضوع و ارزش صفحه تعادل داشته باشد و انباشته از کلیدواژه نباشد.
- description توضیح واقعی صفحه باشد؛ وعده قیمت، تخفیف یا موجودی ندهد.
- عبارت‌های «بهترین»، «ارزان‌ترین» و «قطعی» فقط با معیار و داده قابل اثبات مجازند.

## ساختار بدنه

مقدمه در ۲ تا ۴ جمله پاسخ مستقیم بدهد. هر بخش یک مسئله تصمیم‌گیری را پوشش دهد. فهرست فقط برای موارد قابل اسکن استفاده شود. متن عمومی یکسان با جایگزینی نام شهر، محتوای یکتا محسوب نمی‌شود.

## داده‌های متغیر

برای قیمت، ظرفیت، ساعت پرواز، قوانین ورود، بار و استرداد از عبارت دقیق استفاده کنید: «جزئیات گزینه نهایی را بررسی کنید». داده نمایشی نباید به‌عنوان موجودی واقعی دیده شود. مقررات ویزا یا فرودگاه به منبع رسمی و تاریخ بازبینی نیاز دارند.

## لینک و دسترس‌پذیری

متن لینک مقصد را توضیح دهد؛ «اینجا کلیک کنید» مجاز نیست. alt تصویر باید آنچه در تصویر دیده می‌شود را توصیف کند و کلیدواژه‌چینی نداشته باشد. عنوان‌ها باید سلسله‌مراتب منطقی H1 سپس H2 داشته باشند.

## بازبینی پیش از انتشار

صحت نام‌ها و کدها، یکتایی title/H1/description، منبع ادعاهای متغیر، لینک‌های داخلی، تاریخ بازبینی، canonical و عدم وجود متن نمونه کنترل شود.
