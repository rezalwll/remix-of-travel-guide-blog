# سیاست تحریریه و انتشار

## مسئولیت

تحریریه مالک صحت و خوانایی محتواست؛ مالک SEO intent، canonical و پیوند داخلی را کنترل می‌کند؛ مهندسی اجرای metadata، schema، sitemap و noindex را تضمین می‌کند. انتشار محتوای حساس بدون نام منبع و تاریخ بررسی ممنوع است.

## گردش کار

1. تعریف intent و بررسی نبود صفحه هم‌هدف.
2. انتخاب page type و URL canonical از taxonomy.
3. نگارش محتوای یکتا و ثبت منابع.
4. بازبینی انسانی برای صحت، لحن و ادعاها.
5. عبور از `npm run seo:metadata` و ممیزی خروجی HTML در CI.
6. انتشار تدریجی و پایش index/click/impression.

## اصلاح و حذف

خطای واقعی فوراً اصلاح و تاریخ بازبینی ثبت می‌شود. صفحه منقضی با جایگزین هم‌هدف 308 می‌شود؛ بدون جایگزین واقعی 404/410 می‌گیرد. redirect به صفحه نامرتبط یا صفحه اصلی مجاز نیست. محتوای قدیمی تا زمان بازنویسی `noindex` و خارج از sitemap می‌ماند.

## تعارض منافع و محتوای تجاری

رتبه‌بندی پولی، review ساختگی و ادعای تجربه شخصی غیرواقعی ممنوع است. در صورت فعال‌شدن محتوای اسپانسری، رابطه تجاری باید شفاف و لینک مناسب علامت‌گذاری شود. داده provider فقط پس از اتصال معتبر و با محدودیت freshness منتشر می‌شود.

## استفاده از هوش مصنوعی

خروجی تولیدی پیش‌نویس است و بدون بازبینی انسانی، بررسی منبع و کنترل شباهت منتشر نمی‌شود. هوش مصنوعی منبع حقیقت برای مقررات، ویزا، قیمت یا عملیات سفر نیست.
